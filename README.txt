Δημοτικό Σχολείο Ιππείου — πλήρες πακέτο για GitHub

1. Αποσυμπιέστε το ZIP.
2. Ανεβάστε ΟΛΑ τα αρχεία που περιλαμβάνει απευθείας στη ρίζα του repository
   Dimippeiou/dimippeiou.github.io (όχι μέσα σε φάκελο).
3. Πατήστε Commit changes.
4. Ελέγξτε την αρχική και άλλες σελίδες με Ctrl+F5.

που στάλθηκε ως φωτογραφία, με απομόνωση του λευκού φόντου.
Το sustainable-tourism.jpg είναι η μεγάλη αφίσα της αρχικής.
