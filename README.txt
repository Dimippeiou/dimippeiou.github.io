ΔΙΟΡΘΩΣΗ ΚΟΥΜΠΙΟΥ ΕΛ/EN – ΕΛΛΗΝΙΚΑ ΑΠΟ ΠΡΟΕΠΙΛΟΓΗ

Ανεβάστε ΟΛΑ τα αρχεία του πακέτου στη ρίζα του GitHub repository (όπου βρίσκεται το index.html).
Τα περιλαμβανόμενα αρχεία είναι οι 10 HTML σελίδες, i18n.js, i18n.css, el.json, en.json.
Τα υπάρχοντα style.css και οι φωτογραφίες ΔΕΝ αλλάζουν.
Αρχική γλώσσα ελληνικά, εκτός εάν ο επισκέπτης επέλεξε English από τη νέα έκδοση.
Παλαιότερη αποθηκευμένη επιλογή δεν επηρεάζει αυτή την έκδοση.
Δεν χρησιμοποιείται Google Translate.
