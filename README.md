# Ευρωπαϊκά Προγράμματα – Δημοτικό Σχολείο Ιππείου

## Τι ανεβάζουμε στο GitHub
Ανεβάζουμε **όλα τα αρχεία HTML**, το `style.css` και **ολόκληρο τον φάκελο `images`**, όπως είναι. Στο repository πρέπει να βρίσκεται το `index.html` στην πρώτη (root) θέση.

## Επεξεργασία
- **Αρχική** → `index.html`
- **Το σχολείο** → `school.html`
- **Νέα** → `news.html`
- **Erasmus+** → `erasmus.html`
- **eTwinning** → `etwinning.html`
- **Κινητικότητες** → `mobilities.html`
- **Φωτογραφίες** → `gallery.html`
- **Αποτελέσματα / δεσμεύσεις KA122** → `results.html`
- **Επικοινωνία** → `contact.html`
- **Χρώματα, γραμματοσειρές και κοινή εμφάνιση** → `style.css`
- **Φωτογραφίες και λογότυπα** → φάκελος `images/`

### Αντικατάσταση εικόνας
Στο GitHub ανοίγουμε τον φάκελο images, ανεβάζουμε τη νέα φωτογραφία με *ακριβώς ίδιο όνομα και επέκταση* με το αρχείο που χρησιμοποιεί η σελίδα και επιβεβαιώνουμε την αντικατάσταση (Commit changes). Αλλιώς, ανεβάζουμε με νέο όνομα και ενημερώνουμε τη σχετική αναφορά `src="images/...."` στο αντίστοιχο HTML.

### Προσοχή
Η έκδοση αυτή είναι έτοιμη για τεχνική δημοσίευση, αλλά πριν από την επίσημη δημόσια προβολή: ελέγχουμε άδειες χρήσης των σημάτων/φωτογραφιών και προσθέτουμε το επίσημο έμβλημα χρηματοδότησης της ΕΕ. Τα μη ολοκληρωμένα παραδοτέα παρουσιάζονται ως στόχοι και όχι ως επιτεύγματα. Το κουμπί EN αναγράφει «σύντομα» μέχρι να υπάρχει πραγματική αγγλική μετάφραση.
