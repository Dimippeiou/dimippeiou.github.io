Δημοτικό Σχολείο Ιππείου — ενημέρωση υποσέλιδου

Προστέθηκε το λογότυπο Erasmus+ «Enriching lives, opening minds» στη λευκή ζώνη, σε όλες τις 9 σελίδες, δίπλα στο έμβλημα της ΕΕ. Είναι ενσωματωμένο στο HTML για να μη χαλάει η σύνδεση της εικόνας.

1. Κάνε εξαγωγή του ZIP.
2. Ανέβασε τα αρχεία στην κεντρική λίστα του repository GitHub — όχι τον ίδιο τον φάκελο.
3. Commit changes, και Ctrl+F5 στον ιστότοπο.

Το αρχείο εικόνας Erasmus+ είναι περικοπή από το στιγμιότυπο που παρείχες. Για επίσημη χρήση υψηλής ανάλυσης συνιστάται η επίσημη έκδοση από Εθνική Μονάδα Erasmus+.
